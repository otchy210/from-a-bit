# From a Bit

ひとつのビットから、データの大きさと記憶媒体の歴史を旅する。

From a Bit は、スクロールしながらデータ容量の違いを体感するインタラクティブなインフォグラフィックスです。1 bit のドットから始まり、視点を引きながら、パンチカードから大容量ストレージへと続く記憶媒体の歴史をたどります。

現在制作中です。ローカルのプレビューでは、1 bit から 80.64 PB まで、容量順に並んだ45項目を読めます。

公開予定：[from-a-bit.otchy.net](https://from-a-bit.otchy.net/)
